一、V30升級／首次安裝（一次完成）
1. 手機包解壓一層，把同層9檔上傳自己的GitHub儲存庫。
   alpharadar_core.zip保持原樣，不要再解壓。
2. Add file → Create new file，檔名.github/workflows/pipeline.yml，
   貼上pipeline_workflow_COPY.txt全文並Commit。已有該檔就Edit全選替換。
   只上傳同層9檔，不會自動替換舊工作流程；這一步必須做。
3. Actions → Alpha Radar 雲端資料與模型 → Run workflow。
   mode=auto、action=run。之後每日／週六排程自動更新。
4. Streamlit入口app.py、Python3.12。若未偵測儲存庫，在Secrets加入：
   ALPHARADAR_REPO="你的帳號/儲存庫"
   私有儲存庫另加只讀GITHUB_TOKEN；切勿將Token上傳到程式碼。

三、每天怎麼用
選股儀表板 → 選短／中／長線 → 看原因、族群及資料日。
盤後：以本期名單規劃下一交易日，點個股檢查買區／防守與配置。
盤中：開「盤中確認」，每5秒刷新報價區；須有有效成交時間與價位。
真實OHLC不足，不提供虛構買區。研究候選不等於已證實可獲利。
0050可設0%；配置依單股／族群上限與每筆防守風險預算試算。
模型研究與驗效 → 看淨報酬、成本壓力、五換股日、權重與公告後紀錄。

四、模型管理
每日比較有限候選，週六擴大。連續10不同交易日領先、20交易日冷卻
且通過門檻才自動升級研究冠軍；AUTO_PROMOTE=false停用自動切換。
Actions的action可選lock／unlock／rollback，horizon選short／mid／long。
回復會重建相符名單並鎖定，不只更換模型名稱。
5秒是排程，不保證上游每5秒有新成交；海外情境不偷改公布排名。
